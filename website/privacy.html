Secblitz

Privacy policy

Last updated: 7 October 2026

1. Summary

Secblitz does not collect personal data. It has no account, no ads, no analytics, no telemetry and no crash reporting. Scan results, settings, history and the list of installed apps stay on your PC.

2. Data Secblitz collects

None. Secblitz does not ask for personal details and does not send scan results, settings, history or app lists to anyone. All scans run locally.

The website counts how many times each Secblitz file is downloaded, including automatic updates. Only the file name and a running total are stored. No IP address, cookie or other detail about the download is kept.

3. Network connections

3.1 Automatic updates

If automatic updates were left on during installation, Secblitz checks for a new version once an hour. It downloads a small signed file from secblitz.lol that names the latest version. If a newer version exists, it downloads the installer from secblitz.lol, verifies the signature and installs it while Secblitz is not in use.

These requests contain no account, name or information about your PC. As with any website, secblitz.lol receives your IP address and the time of the request. To turn updates off, run the installer again and clear the update option, or remove Secblitz.

3.2 Web protection

Web protection is off by default. When it is on:

  • Secblitz downloads block lists daily or weekly from AdGuard (adguardteam.github.io, filters.adtidy.org) and EasyList (easylist.to). Each request identifies Secblitz and its version.
  • Website name lookups from your PC go through Secblitz. Names on a block list receive a "not found" answer. All other lookups are forwarded to the name servers your network already uses, or to Quad9 if none are available. Quad9 has its own privacy policy.
  • Secblitz does not store the names you look up. It keeps only a daily count of blocked lookups.

Private internet lookups is a separate switch and is off by default. When it is on, website name lookups leave your PC encrypted and go to Quad9, a Swiss non-profit that does not log IP addresses, so your internet provider or a public Wi-Fi network cannot read them. Names that only exist on your own network are never sent there. If your network does not let encrypted lookups through, Secblitz uses your network's usual name servers instead and tries again after two minutes.

Turning web protection off restores your PC's previous network settings.

3.3 Actions you start

  • Installing Bitwarden or updating apps uses winget, which downloads from Microsoft and the app's publisher.
  • Installing Windows updates or updating virus protection is done by Windows, which downloads from Microsoft. Secblitz sends no data of its own.
  • Opening the Microsoft Store opens it in Windows, where Microsoft's terms apply.
  • Report a problem, Suggest a feature and the privacy link in Settings open a page in your web browser. GitHub pages are operated by GitHub.

4. Data stored on your PC

  • C:\ProgramData\Secblitz, readable only by administrators: the record of changes and how to undo them, the latest scan, history, language and theme, web protection lists, and saved copies of removed apps.
  • Your user profile: a small file listing the personal Windows settings Secblitz changed, so they can be undone.

This data is not sent anywhere.

5. Removing Secblitz

Uninstalling Secblitz deletes both locations above. Windows updates, apps installed through Secblitz and settings you chose to keep are not changed.

6. Changes to this policy

Changes are published on this page, and the date at the top is updated.
