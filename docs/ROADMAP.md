# Secblitz roadmap

This is what we plan to build next, in plain words. Plans can change, and a date is never a promise. Secblitz is free and open source, and it is not planned for the Microsoft Store.

## 1.0

- A short welcome the first time you open Secblitz, so nothing is checked until you say yes.
- Clearer windows and details, showing one short line for each point and the rest only when you ask.
- A Help page inside Settings, and a support file you can choose to send us when something goes wrong.
- Use with the keyboard throughout, and an honest accessibility statement.
- Signed releases, once the signing programme approves Secblitz.
- A parts list with each release, so anyone can see what the code is built from.

## 1.1

- More languages, with a way for the community to help translate.
- An optional weekly summary of how your PC is doing.
- Support for the new "Administrator protection" in Windows.

## 1.2

- An independent security audit, with a summary we publish.
- Builds that anyone can reproduce, to confirm the published files match the code.

## Later

- Helping you look after a family member's PC, without remote control.
- Blocking chosen apps from reaching the internet.
- A check of your home router.

To suggest something, open an issue at https://github.com/secblitz/Secblitz/issues.
